# Tipografía de la intro

DM Serif Display Regular, Colophon Foundry, distribuida con SIL Open Font License 1.1 (archivo adjunto).

Fuente oficial: https://github.com/google/fonts/tree/main/ofl/dmserifdisplay

Se convirtió el archivo TTF a WOFF con FontTools sin alterar sus glifos y se integró en intro.css. No requiere servicios de fuentes externos ni instalación en las PC. Se utiliza solo en el nombre Cimagraf de la bienvenida.
